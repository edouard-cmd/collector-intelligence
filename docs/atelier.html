ta situation

Ce prix n'est pas transmis au modèle pendant l'identification et la recherche : il ne peut pas les orienter. Il ne lui est communiqué qu'à la toute fin, pour l'avis de l'expert, une fois les prix du marché établis.

histoire du modèle

D'où vient ce modèle, pourquoi il est recherché, ce qui a fait bouger sa cote. Rédigée pendant l'identification, à partir des mêmes pages : quelques centimes au lieu d'un appel séparé. Chaque fait daté renvoie à sa source ; une source que le modèle n'a pas réellement consultée est signalée. Le bouton la régénère seule si elle est trop mince (environ 0,20 €).

marché : annonces et ventes réelles

Cherche sur le web les fiches individuelles de cet objet sur les places de marché : chaque ligne est un article réel, avec son lien. Les prix sont ceux affichés sur la fiche ; l'analyse est calculée sur ces seules fiches, jamais estimée. Une fiche dont l'adresse n'a pas été réellement consultée est mise de côté.

synthèse

Tout ce qu'il faut retenir, au même endroit : l'objet, les prix observés, ton prix face au marché, puis l'avis de l'expert. Tous les chiffres sont calculés par le code sur les fiches trouvées ; l'avis de l'expert, rédigé par l'IA, les interprète sans en inventer.

Indique ta situation et un prix dans le bloc 1 ; le verdict apparaîtra après la recherche sur le marché.
